# Bank Loan Portfolio & Risk Analytics

## Project Overview

This project analyzes a financial loan portfolio to understand loan applications, funding patterns, borrower characteristics, interest rates, and portfolio risk indicators.

The analysis combines Python-based exploratory data analysis, SQL business queries, and Tableau visualization to convert raw loan data into meaningful portfolio insights.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Tableau
- Jupyter Notebook

## Analysis Performed

### Python EDA
- Loaded and explored the financial loan dataset using Pandas.
- Performed data inspection and preprocessing.
- Analyzed loan status distribution and major loan purposes.
- Examined average interest rates across loan grades.
- Compared average DTI across loan statuses.
- Created an income-to-loan ratio feature for additional borrower analysis.
- Created visualizations using Matplotlib and Seaborn.

### SQL Analysis
- Analyzed loan application and portfolio metrics.
- Examined loan status and borrower-related patterns.
- Added an analysis of average interest rate by loan grade.
- Used SQL queries to answer business-oriented portfolio questions.

### Tableau Dashboard
Created an interactive dashboard covering:

- Total Loan Applications
- Total Funded Amount
- Average Interest Rate
- Average DTI
- Loan Status Distribution
- Loan Purpose Analysis
- Average Interest Rate by Loan Grade

## Key Skills Demonstrated

Data Cleaning • Exploratory Data Analysis • SQL Analysis • Data Visualization • Business Analytics • Dashboard Development
